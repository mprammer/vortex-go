# Wrapped Pco decoder

Independent Go implementation of the wrapped Pco 4.1 representation used by Vortex, derived from the Apache-2.0-licensed `pco` Rust crate version 1.0.3 (pcodec/pcodec). No code from the previous Go Vortex reader is used.

Reference modules: `metadata/{chunk,mode,delta_encoding,chunk_latent_var,page_latent_var}.rs`, `ans/{spec,decoding}.rs`, `wrapped/page_decompressor.rs`, `page_latent_decompressor.rs`, `delta/{consecutive,lookback,conv1}.rs`, `mode/{classic,int_mult,float_mult,float_quant,dict}.rs`, and `data_types/{signed,unsigned,float}.rs`. The implementation uses checked bit reads without speculative padding. It returns little-endian values before Vortex validity expansion.

The immutable `testdata/modes.json` was generated by the independently Rust-backed Iceberg regression generator, retained in `dev/fixtures/src/bin/pco_modes.rs`. It covers 59 combinations of numeric types, modes and delta transforms, including pages around the 256-value batch boundary. Tests compare exact output bytes and reject truncated metadata/pages.
